## 0.1.0

- Initial release.
- Widget-to-image watermark rendering using Flutter widgets.
- Single, tiled, diagonal, custom, and multi-watermark support.
- PNG and JPEG output support.
- Preview widget for UI prototyping.
- Added `analysis_options.yaml` with stricter linting.
- Added test coverage for config factories, layout factories, and alignment resolution.
- Improved public API naming with `WidgetWatermark` aliases and clearer `applyTo*` method names.
- Kept `FlutterWidgetWatermark` and legacy `apply*` methods for backward compatibility.
- Expanded README for pub.dev with installation, examples, API overview, and limitations.
- Updated example app to cover bytes, URL, path, preview, and multi-watermark flows.
